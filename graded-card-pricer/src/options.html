Behavior

Currency

All prices are shown in Canadian dollars. eBay is searched on eBay.ca. Collectr, Alt and Card Ladder show CAD if you set CAD in your account there. The extension also switches Collectr’s currency menu to CAD. Prices in other currencies (PriceCharting and 130point in US$, SNKRDUNK in ¥) are converted at the Bank of Canada daily rate and marked “≈”. Every matching sale counts, best offers included.

eBay.ca sellers

API keys (stored on this computer only)

eBay: your Production App ID and Cert ID (developer.ebay.com → Application Keys) power the Current listings section (cheapest matching Buy It Now listings on eBay.ca) through eBay's standard listings API. eBay has closed its sold-items API (Marketplace Insights) to new apps, so sold prices come from the eBay.ca website, Terapeak (connect it in the panel) and 130point.

Pokemon Price Tracker: its API key (pokemonpricetracker.com → API keys) adds its eBay graded-sales database to every search. Paid plans give a per-grade summary (smart market price, median, trend). The Business plan also returns every individual sold listing, and those join your sales list. Each search uses about 8–13 credits.

Platforms

{q} is replaced with the search text. Alt and Collectr have no public price API. They open as phone-sized mini views (or a 📱 phone window where you’re signed in), and the extension reads the sold data from the page. Alt, Collectr and Card Ladder need your login: connect each one from the panel (📱 Connect) and sign in once. If a site changes its search URL, update it here.
