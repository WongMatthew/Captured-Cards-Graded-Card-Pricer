Behavior

Currency

All prices are shown in Canadian dollars. eBay is searched on eBay.ca. Collectr, Alt and Card Ladder show CAD if you set CAD in your account there. The extension also switches Collectr’s currency menu to CAD. Prices that still come through in US$ (PriceCharting, most of 130point) are converted at the Bank of Canada daily rate and marked “≈”.

eBay.ca sellers

API keys (stored on this computer only)

eBay: with an eBay developer key approved for the Marketplace Insights (sold items) API, eBay.ca sales load directly, with exact sale times and no “Open sold results” step. Create keys at developer.ebay.com → Application Keys (Production), then request Marketplace Insights access. eBay approves this API case by case. Until then the extension uses the eBay.ca website.

PSA: with a PSA API key, PSA cert numbers are looked up instantly (with population). Get one at psacard.com → sign in → Public API.

Platforms

{q} is replaced with the search text. Alt and Collectr have no public price API. They open as phone-sized mini views (or a 📱 phone window where you’re signed in), and the extension reads the sold data from the page. Alt, Collectr and Card Ladder need your login: connect each one from the panel (📱 Connect) and sign in once. If a site changes its search URL, update it here.
